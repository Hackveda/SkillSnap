# SkillSnap Architecture Map

The final architecture diagram will be added after the `/public_html/skillsnap` deployment has been validated end-to-end on the server.

When added, it should show:

1. Candidate/Admin UI
2. Resume upload and extraction
3. `skillsnap_job_details` market-data source
4. Requirement aggregation
5. Keyword + Generative AI evidence analysis
6. Human/candidate review override
7. Readiness analytics and preparation prescription
8. Company/job matching
9. Shared candidate profile
10. ATS resume generation
11. Isolated `skillsnap_*` MySQL tables
